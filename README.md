# おみくじアプリ

コマンドプロンプトで動く、Java のおみくじアプリです。

## 使い方

1. `run-app.bat` をダブルクリックします。
2. `1` を入力して Enter を押すと、大吉・中吉・小吉・吉・末吉・凶・大凶のどれかが表示されます。
3. `2` を入力して Enter を押すと終了します。

`1` と `2` 以外を入力すると「1か2を入力してください。」と表示され、もう一度入力できます。

## 画面の例

```text
=== おみくじ ===
1: おみくじを引く / 2: 終了
> 1
あなたの運勢は【末吉】です。
1: おみくじを引く / 2: 終了
> 2
終了します。
```

## テストの実行

プロジェクトのトップで実行します。

```
java-portable_20260715\jdk-25.0.3_gui_min\bin\javac.exe -encoding UTF-8 -d build src\*.java test\*.java
java-portable_20260715\jdk-25.0.3_gui_min\bin\java.exe -Dstdout.encoding=UTF-8 -ea -cp build OmikujiTest
```

最後に「すべてのテストに合格しました。」と表示されれば成功です。

## 動かすのに必要なもの

`java-portable_20260715` フォルダ(Java 25)がプロジェクトのトップに置いてあること。
